Phone Mirror Plug in your phone with USB debugging on, then click Connect.
  1. Phone: Settings > About phone > tap Build number 7 times.
  2. Settings > System > Developer options > turn on USB debugging.
  3. Plug in USB, set USB mode to File transfer if asked.
  4. Click Connect, pick the phone, tap Allow on the phone.

Controls: click/drag = touch, right-click = Back, scroll wheel = scroll, click the screen then type to send text.
